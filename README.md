# 🍔 JALIKUD

> **A Full-Stack Fast-Food Restaurant Ordering System**

---

## 📌 Project Description

**JALIKUD** is a full-stack fast-food restaurant system designed to streamline food ordering and restaurant operations. The system aims to provide customers with a convenient way to browse products, place orders, and potentially earn and redeem rewards through a points-based system.

The specific features and system scope are currently under development.
