# 🍔 JALIKUD

> **A Full-Stack Fast-Food Restaurant Ordering System**

---

## 📌 Project Description

**JALIKUD** is a full-stack fast-food restaurant ordering system inspired by modern mobile ordering platforms such as the McDonald's app. It is designed to provide customers with a convenient way to browse the menu, customize their orders, place orders, and earn rewards through a points-based system.

The system will also generate a unique **order or redemption code** that customers can present to the cashier for order verification and fulfillment.
